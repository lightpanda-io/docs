# Puppeteer, Playwright & other client libraries

Connect Puppeteer, Playwright, Chromedp, or Selenium to Lightpanda in under 10 minutes, and read content that only exists once a page's JavaScript runs. Get the same automation you already know, running faster and lighter than Chrome.

## Steps

### Connect and read JS-rendered content

The script opens [quotes.toscrape.com/js](https://quotes.toscrape.com/js/) and prints the first quote. The quotes are rendered by JavaScript, so a plain HTTP fetch returns an empty list: Lightpanda runs that JavaScript before your script reads the page.

<Tabs items={['Puppeteer', 'Playwright', 'Chromedp', 'Selenium']} className="-mb-4" storageKey="quickstart-client">
  <Tabs.Tab>
Save as `index.js`:

```js copy
'use strict'

import puppeteer from 'puppeteer-core'

const browser = await puppeteer.connect({
  browserWSEndpoint: 'ws://127.0.0.1:9222',
})

const context = await browser.createBrowserContext()
const page = await context.newPage()

await page.goto('https://quotes.toscrape.com/js/')

const quote = await page.$eval('.quote .text', el => el.textContent)
console.log(quote)

await page.close()
await context.close()
await browser.disconnect()
```

Find more [Puppeteer options](/usage/cdp/puppeteer).
  </Tabs.Tab>

Save as `main.go`:

```go copy
package main

import (
	"context"
	"log"

	"github.com/chromedp/chromedp"
)

func main() {
	allocCtx, cancel := chromedp.NewRemoteAllocator(context.Background(),
		"ws://127.0.0.1:9222", chromedp.NoModifyURL,
	)
	defer cancel()

	ctx, cancel := chromedp.NewContext(allocCtx)
	defer cancel()

	var quote string
	if err := chromedp.Run(ctx,
		chromedp.Navigate("https://quotes.toscrape.com/js/"),
		chromedp.Text(".quote .text", &quote, chromedp.ByQuery),
	); err != nil {
		log.Fatalf("failed getting the quote: %v", err)
	}

	log.Println("quote:", quote)
}
```

Find more [Chromedp options](/usage/cdp/chromedp).

  <Tabs.Tab id="connect-selenium-js" className="m-0">
Request a BiDi session by setting the `webSocketUrl` capability to `true`, then drive it with BiDi commands. Save as `index.js`:

```js copy
'use strict'

import { Builder, Capabilities } from 'selenium-webdriver'
import { BrowsingContext } from 'selenium-webdriver/bidi/generated/browsing_context.js'
import { Script } from 'selenium-webdriver/bidi/generated/script.js'

const caps = new Capabilities()
caps.set('browserName', 'lightpanda')
caps.set('webSocketUrl', true)

const driver = await new Builder()
  .usingServer('http://127.0.0.1:9222')
  .withCapabilities(caps)
  .build()

const bidi = await driver.getBidi()
await bidi.waitForConnection()

const browsingContext = new BrowsingContext(bidi)
const script = new Script(bidi)

const { context } = await browsingContext.create({ type: 'tab' })
await browsingContext.navigate({ context, url: 'https://quotes.toscrape.com/js/', wait: 'complete' })

const quote = await script.evaluate({
  expression: "document.querySelector('.quote .text').textContent",
  target: { context },
  awaitPromise: false,
})
console.log(quote.result.value)

await browsingContext.close({ context })
await driver.quit()
```
  </Tabs.Tab>
  <Tabs.Tab id="connect-selenium-py" className="m-0">
Request a BiDi session by setting the `webSocketUrl` capability to `True`, then drive it with BiDi commands. Save as `script.py`:

```python copy
import os

from selenium.webdriver.common.options import ArgOptions
from selenium.webdriver.common.bidi.common import command_builder
from selenium.webdriver.remote.webdriver import WebDriver

options = ArgOptions()
options.set_capability("browserName", "lightpanda")
options.set_capability("webSocketUrl", True)

driver = WebDriver(command_executor="http://127.0.0.1:9222", options=options)

context = driver.browsing_context.create(type="tab")
driver.browsing_context.navigate(context=context, url="https://quotes.toscrape.com/js/", wait="complete")

# driver.script doesn't expose evaluate yet, so build the BiDi command directly.
result = driver.browsing_context._conn.execute(command_builder(
    "script.evaluate",
    {"expression": "document.querySelector('.quote .text').textContent", "target": {"context": context}, "awaitPromise": False},
))
print(result["result"]["value"], flush=True)

driver.browsing_context.close(context)
driver.quit()

# Selenium's BiDi thread outlives quit(); force the process to exit instead.
os._exit(0)
```

## Go to production

Switch to [Lightpanda Cloud](/run-on-lightpanda-cloud/getting-started) by exporting your token and connecting over `wss://` instead of `ws://`:

```sh copy
export LPD_TOKEN="your token here"
```
