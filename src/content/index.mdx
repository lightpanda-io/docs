# Lightpanda documentation

<div className="mt-6 border-l-2 border-[var(--primary)] pl-4 text-lg font-medium text-[var(--foreground)]">
  The headless browser built for machines: 9x faster than Chrome, with 16x less memory.
</div>

Built from scratch with no graphical rendering, Lightpanda starts instantly and uses little memory, so you can run far more sessions on the same hardware. It still executes JavaScript and supports the Web APIs modern sites rely on, so it fits AI agents, LLM training, search indexing, scraping, and testing. See [what is Lightpanda](/core-concepts/what-is-lightpanda) for why it exists and how it fits your stack.
