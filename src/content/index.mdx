Lightpanda is a headless browser built from scratch for machines, with no graphical rendering. It starts instantly, runs pages **9x faster** than Chrome, and uses **16x less** memory, so you can run far more sessions on the same hardware. See [what is Lightpanda](/core-concepts/what-is-lightpanda) for why it exists and how it fits your stack.
