# Package managers

## Homebrew

Install the latest release using Homebrew.

```sh copy
brew install lightpanda-io/browser/lightpanda
```

You can alternatively use the last nightly version with:
```sh copy
brew install lightpanda-io/browser/lightpanda-nightly
```

## Arch Linux User Repository

```sh copy
yay -S lightpanda-bin
```

You can alternatively use the last nightly version with:
```sh copy
yay -S lightpanda-nightly-bin
```

## Debian/Ubuntu

Install Lightpanda from the [APT repository](https://github.com/lightpanda-io/browser-apt).

Prerequisites:

- Root access: run the commands below as root.
- `ca-certificates` and `curl` installed.

```sh copy
install -m 0755 -d /etc/apt/keyrings

curl -fsSL -o /etc/apt/keyrings/lightpanda.asc \
  https://apt.lightpanda.io/lightpanda.asc
curl -fsSL -o /etc/apt/sources.list.d/lightpanda.sources \
  https://apt.lightpanda.io/lightpanda.sources
chmod 0644 /etc/apt/keyrings/lightpanda.asc /etc/apt/sources.list.d/lightpanda.sources

apt-get update && apt-get install -y lightpanda
```

New releases then come with regular APT upgrades.

## Telemetry

By default, Lightpanda collects and sends usage telemetry. This can be disabled by setting an environment variable `LIGHTPANDA_DISABLE_TELEMETRY=true`. For more on telemetry, see [Confidentiality and telemetry](/core-concepts/local-vs-cloud#confidentiality-and-telemetry).
