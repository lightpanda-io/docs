# Systems requirements

- Debian 12, Ubuntu 22.04, Ubuntu 24.04, on x86-64 architecture (glibc 2.35 or later).
- Debian 13, Ubuntu 24.04, on arm64 architecture (glibc 2.38 or later).
- macOS 14.8.9 Sonoma, or later.
- Windows 10+ or Windows Server 2016+, through Windows Subsystem for Linux (WSL).
