# Build from sources

## Prerequisites

Lightpanda is written with [Zig](https://ziglang.org/) `0.17.0`. You will have to
install it with the right version in order to build the project.

You need also to install [Rust](https://rust-lang.org/tools/install/) for building deps.

Lightpanda also depends on
[v8](https://chromium.googlesource.com/v8/v8.git) (through [zig-v8-fork](https://github.com/lightpanda-io/zig-v8-fork/), our Zig wrapper around v8),
[Libcurl](https://curl.se/libcurl/), [html5ever](https://github.com/servo/html5ever) and [SQLite](https://sqlite.org/).
The build fetches them; the full list is in [`build.zig.zon`](https://github.com/lightpanda-io/browser/blob/main/build.zig.zon).

You have to install some libs:

**For Debian/Ubuntu based Linux:**

```bash copy
sudo apt install xz-utils ca-certificates \
        pkg-config libglib2.0-dev \
        clang make curl git
```

`pkg-config` and `libglib2.0-dev` are only needed to build V8 from source (see
[Build and run](#build-and-run)).

**For Linux with [Nix](https://nixos.org/download/), you can use the devShell:**

```bash copy
nix develop
```

**For MacOS, you need [Xcode](https://developer.apple.com/xcode/) and the following pacakges from homebrew:**

```bash copy
brew install cmake
```

## Build and run

Lightpanda embeds the V8 JavaScript engine. The build either compiles V8 from
source, which takes several minutes, or uses a
[precompiled copy](https://github.com/lightpanda-io/zig-v8-fork/releases). To use
the precompiled copy, run this once:

```bash copy
make download-v8
```

It downloads the V8 version Lightpanda needs into `.lp-cache/`. `make build` and
`zig build` then use it instead of compiling V8. To use a V8 library stored
elsewhere, pass its path with `-Dprebuilt_v8_path=`.

<Callout type="info" emoji="ℹ️">
    If no precompiled V8 exists for your platform, `make download-v8` fails. Skip
    it: the build compiles V8 from source.
</Callout>

Then build the entire browser with `make build` or `make build-dev` for debug
env.

To build in debug mode and start the browser in one step, use Zig directly:

```bash copy
zig build run
```

### Embed v8 snapshot

Lightpanda uses a v8 snapshot. `make build` builds and embeds it. With a plain
`zig build`, it is created on startup instead, unless you embed it by using the
following commands:

Generate the snapshot.
```bash copy
zig build snapshot_creator -- src/snapshot.bin
```

Build using the snapshot binary.
```bash copy
zig build -Dsnapshot_path=../../snapshot.bin
```

Embedding it moves the snapshot creation from each startup to build time, so the browser starts faster.

## Telemetry

By default, Lightpanda collects and sends usage telemetry. This can be disabled by setting an environment variable `LIGHTPANDA_DISABLE_TELEMETRY=true`. You can read Lightpanda's privacy policy at: [https://lightpanda.io/privacy-policy](https://lightpanda.io/privacy-policy).
