# Getting started

Lightpanda Cloud gives you a remote browser you reach with an API token. You sign up, generate a token, and point your CDP client at a cloud endpoint. There is no browser process to install or keep alive.

## Create an account and token

Sign up at [console.lightpanda.io/signup](https://console.lightpanda.io/signup). After you sign up, you receive an email with a link to generate your API token.

<Callout type="warning">
Your token is shown once, when you generate it. Save it somewhere safe. If you lose it, generate a new one from the console.
</Callout>

## Connect a browser

Your token authenticates every request. Export it, then point your CDP client at the cloud endpoint. Any client that speaks CDP connects the same way.

Prefer not to hand-write the snippet? The [script generator](https://console.lightpanda.io/tools/script-generator) in the console walks you through your client and region, then hands you a ready-to-paste connection snippet with your token already filled in.

### Endpoints and browser

Connect to the region nearest your script:

- `wss://euwest.cloud.lightpanda.io/ws` (west Europe)
- `wss://uswest.cloud.lightpanda.io/ws` (west US)

The cloud serves Lightpanda by default. For debugging, append `browser=chrome` to run Google Chrome instead, since Chrome isn't intended for production traffic. Append `browser=lightpanda` to force Lightpanda explicitly. To route traffic through a proxy, see [Configure a proxy](/guides/configure-a-proxy).

## Other ways to connect

CDP is not the only option. The cloud also exposes:

- **[HTTP API](/usage/api)**: fetch a page's HTML or Markdown in a single request, with no CDP script.
- **[MCP](/usage/mcp)**: drive the browser from AI applications over the Model Context Protocol.

## Manage your account

Sign in to the [console](https://console.lightpanda.io) with your email and password. From there you create and revoke tokens, review recent sessions and their logs, track usage, manage billing, and configure proxies. See [Console](/run-on-lightpanda-cloud/console) for a tour and [Limits and billing](/run-on-lightpanda-cloud/limits-and-billing) for plans and how usage is charged.
