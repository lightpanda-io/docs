# MCP tools

The Lightpanda MCP server exposes these tools and resources, started with [`lightpanda mcp`](/reference/cli/mcp). See [how to use MCP](/usage/mcp) for practical documentation.

Each browser tool below links to its full description and arguments in the [browser tools reference](/reference/browser-tools); the MCP server, the agent and scripts share the same tools. The Hints column carries the tool's MCP annotations, and **page state** marks the tools that return `structuredContent`.

## Calling a tool

Every call goes through the MCP `tools/call` method, with `name` and `arguments` populated from the tools below.

```json
{"jsonrpc":"2.0","id":2,"method":"tools/call",
 "params":{"name":"fill","arguments":{"selector":"#search","value":"lightpanda"}}}
```
```json
{"result":{"content":[{"type":"text","text":"Filled element (selector: #search) with \"lightpanda\". Page url: https://example.com, HTTP 200 OK, title: Example Domain"}],
 "structuredContent":{"url":"https://example.com","httpStatus":200,"title":"Example Domain"},"isError":false}}
```

## Tool results

### Page state

The tools marked **page state** return `structuredContent`, declared by each tool's `outputSchema` in `tools/list`, with these fields:

- `url`: the page URL, always present.
- `httpStatus`: the HTTP status, absent before any response arrives.
- `title`: the page title.

Their text also ends with the page state. `goto` ends with `Navigated. HTTP <status>.`, and the tools that act on the page end with:

```
Page url: <url>, HTTP <status>, title: <title>
```

A 4xx or 5xx status means the page is an error page, not the content. For how `goto` reports a failed navigation or a timeout, see [Known behaviors](/usage/mcp#known-behaviors).

### Page notes

When a tool navigates, its text can start with notes on what the page lacks:

- WebGL: `The page asked for WebGL, which Lightpanda does not provide: anything it renders that way is missing.`
- Iframes: `<n> iframe(s) were not loaded: subframe loading is off.`
- Refused requests: some of the page's own requests were refused with HTTP 403/429 or blocked by a bot challenge.

An error page or a bot challenge page starts with:

- 4xx or 5xx page: `HTTP <status>: this is likely an error or rate-limit page, not the requested content.`
- Bot challenge page: `Blocked by a <vendor> bot challenge (HTTP <status>): this is not the requested content.`

Any tool's text can also start with the WebMCP tools the page registers, when that set changed since the last call:

- `The page registers WebMCP tools; callPageTool runs one:` followed by their JSON.
- `The page no longer registers WebMCP tools.`
