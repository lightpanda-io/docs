# HTTP API

Fetch a URL and retrieve the rendered page. See [how to use the HTTP API](/usage/api) for practical documentation.

## Fetch a URL

The `POST /api/fetch` endpoint returns a JSON message containing the page's content.

### Request

The request requires a bearer authorization header with your token and the `Content-Type: application/json` header. You can pass the token as a `token` query parameter instead of the header.

The endpoint accepts the following parameters:

| Parameter | Type | Required | Default | Description |
|---|---|---|---|---|
| `url` | string | Yes | — | The URL to fetch. |
| `output_format` | `html` \| `markdown` | No | `html` | — |
| `wait_ms` | uint | No | `5000` | Maximum time to wait for `wait_event`, in milliseconds. On timeout, the page is returned as it is. `0` also falls back to the default; it doesn't mean "don't wait". |
| `wait_event` | `DOMContentLoaded` \| `load` \| `networkAlmostIdle` \| `networkIdle` | No | `networkIdle` | Event to wait for before retrieving the page. |
| `raw` | bool | No | `false` | If true, the raw HTML or markdown is returned directly, without the JSON wrapper, with `Content-Type: text/html` or `text/plain` respectively. |
| `proxy_name` | string | No | `fast_dc` | Proxy to route the request through: `fast_dc` (the region's default), `datacenter`, or the identifier of a proxy you added in the console. Up to 32 characters. See [use a proxy on Lightpanda Cloud](/guides/configure-a-proxy#use-a-proxy-on-lightpanda-cloud). |
| `country` | string | No | — | Two-letter country code, case-insensitive. Only used with the `datacenter` proxy. |

```sh copy
curl -XPOST \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  https://euwest.cloud.lightpanda.io/api/fetch \
  --data '{
    "url": "https://lightpanda.io",
    "output_format": "markdown",
    "wait_ms": 50000,
    "wait_event": "networkIdle",
    "raw": false
  }'
```

### Response

If the request sets `raw` to `false`, a JSON response is returned.

| Field | Type | Description |
|---|---|---|
| `data` | string | The page's content, in the format specified by the `output_format` parameter. |
| `status` | int | The response status code. |
| `headers` | object, optional | The HTTP headers returned by the server. |

```json copy
{
  "data": "\n# Example Domain\n\nThis domain is for use in documentation examples without needing permission. Avoid use in operations.\n\n[Learn more](https://iana.org/domains/example)\n",
  "status": 200,
  "headers": {
    "age": "10026",
    "allow": "GET, HEAD",
    "cf-cache-status": "HIT",
    "cf-ray": "9f0dd9374a2320ab-IAD",
    "content-encoding": "br",
    "content-type": "text/html",
    "date": "Thu, 23 Apr 2026 15:19:47 GMT",
    "last-modified": "Sat, 18 Apr 2026 00:51:00 GMT",
    "server": "cloudflare"
  }
}
```

### Errors

Errors return a plain-text body instead of the JSON response.

| Status | Cause |
|---|---|
| `400` | The body has an unknown field or an invalid value. For an invalid value, the body starts with the parameter's name, for example `wait_event: bad wait event`, `format: bad format`, `proxy_name: bad proxy` or `country: bad country`. |
| `401` | The token is missing or invalid. |
| `415` | The `Content-Type` header isn't `application/json`. |
| `429` | A [plan limit](/run-on-lightpanda-cloud/limits-and-billing#when-you-reach-a-limit) is reached, or no browser is free in the region right now. |
| `500` | The fetch failed or the service hit an error. A failed fetch returns a body that starts with `fetch:`. |
