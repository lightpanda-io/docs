# Puppeteer

Use Lightpanda with [Puppeteer](https://pptr.dev/) via the [Chrome DevTools Protocol](https://chromedevtools.github.io/devtools-protocol/) (CDP).

More examples in [demo/puppeteer](https://github.com/lightpanda-io/demo/tree/main/puppeteer).

## Connect Puppeteer

<Tabs items={['Local', 'Cloud']}>
  <Tabs.Tab>
Start Lightpanda as a local CDP server (find all options in the [serve command reference](/reference/cli/serve#options)):

```sh copy
lightpanda serve --host 127.0.0.1 --port 9222
```

Connect Puppeteer using `browserWSEndpoint` — the WebSocket URL Puppeteer uses to attach to an already-running browser instead of launching one itself:

```js copy
'use strict'

import puppeteer from 'puppeteer-core'

const browser = await puppeteer.connect({
  browserWSEndpoint: 'ws://127.0.0.1:9222',
})

const context = await browser.createBrowserContext()
const page = await context.newPage()

await page.goto('https://wikipedia.com/')

const title = await page.title()
console.log(title)

await page.close()
await context.close()
await browser.disconnect()
```
  </Tabs.Tab>
  <Tabs.Tab>
Set your API token and connect to the cloud endpoint. The connection uses `wss://` (WebSocket over TLS) instead of the local `ws://`:

```sh copy
export LPD_TOKEN="your token here"
```

```js copy
'use strict'

import puppeteer from 'puppeteer-core'

const browser = await puppeteer.connect({
  browserWSEndpoint: 'wss://euwest.cloud.lightpanda.io/ws?token=' + process.env.LPD_TOKEN,
})
const context = await browser.createBrowserContext()
const page = await context.newPage()

// ...

await page.close()
await context.close()
await browser.disconnect()
```

In the [playground](/run-on-lightpanda-cloud/playground), the console builds this URL for you and exposes it as `CDP_WS_URL`. Pass `process.env.CDP_WS_URL` to `browserWSEndpoint` there, since `LPD_TOKEN` does not exist in that runtime.

## Cloud options

### Endpoints

Connect to the region nearest to you:

- `wss://euwest.cloud.lightpanda.io/ws` (Europe West)
- `wss://uswest.cloud.lightpanda.io/ws` (US West)

### Browser

By default the cloud runs [Lightpanda](https://github.com/lightpanda-io/browser). Use `browser=chrome` to request a Google Chrome instance instead, or `browser=lightpanda` to explicitly force Lightpanda.

```text copy
wss://euwest.cloud.lightpanda.io/ws?browser=chrome&token=TOKEN
```

### Proxies

The `proxy` parameter controls the outbound IP the cloud browser uses when fetching pages — useful for geo-targeting or avoiding rate limits.

**fast_dc** — default. A single shared datacenter IP, optimized for speed.

**datacenter** — a pool of shared datacenter IPs with automatic rotation. Accepts an optional `country` parameter (two-letter country code) to target a specific country.

```text copy
wss://euwest.cloud.lightpanda.io/ws?proxy=datacenter&country=de&token=TOKEN
```

[Contact us](mailto:hello@lightpanda.io) for additional proxy options.

## Lightpanda commands

Lightpanda adds its own CDP commands, the [LP domain](/reference/cdp-lp-domain). Puppeteer sends them through a CDP session: open one on the page and send the command by name.

A selection of commands, by task:

| Task | Command |
|---|---|
| Get the page as Markdown, HTML, PNG or PDF, after your clicks and form fills | `LP.dump` |
| Get a compact outline of the page, with node IDs | `LP.getSemanticTree` |
| Click or fill a node by its ID | `LP.clickNode`, `LP.fillNode` |
| Tell a blocked or broken page from an empty one | `LP.getPageStatus` |
| Skip images, iframes or other sub-resources for this connection | `LP.configureLoading` |

Find every command, with its parameters and result, in the [LP domain reference](/reference/cdp-lp-domain#reading-the-page).

In the local example, after `page.goto`, add:

```js copy
const client = await page.createCDPSession()
const { content } = await client.send('LP.dump', { format: 'markdown' })
console.log(content)
```
