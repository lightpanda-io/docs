# Use a proxy

Lightpanda supports using your own proxy, both locally and on Lightpanda Cloud. On Lightpanda Cloud, you can also use a shared proxy we provide instead.

<Tabs items={['Local', 'Cloud']}>
  <Tabs.Tab>
## Use a proxy locally

To use a proxy, start Lightpanda from the command line with `--http-proxy` followed by an HTTP or HTTPS proxy address. All outgoing requests go through the proxy, regardless of the protocol your client uses to connect to Lightpanda.

The examples below use `serve`, but `fetch`, `mcp`, and `agent` accept these options too.

```sh copy
lightpanda serve --http-proxy http://127.0.0.1:3000
```

### Authenticate with basic auth

Add [basic auth](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Authentication#basic) credentials to the proxy address with the `username:password@` format.

```sh copy
lightpanda serve --http-proxy 'http://me:my-password@127.0.0.1:3000'
```

### Authenticate with a bearer token

`--proxy-bearer-token` authenticates with [bearer auth](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Authentication#bearer). It adds a `Proxy-Authorization` header to all outgoing requests.

```sh copy
lightpanda serve --http-proxy 'http://127.0.0.1:3000' --proxy-bearer-token 'MY-TOKEN'
```

### Authenticate from your script

You can also pass the proxy credentials from your Puppeteer or Playwright script instead of the command line.

Selenium can't do this, because Lightpanda does not support proxy authentication over WebDriver BiDi. Put the credentials in the `--http-proxy` URL instead.

<Tabs items={['Puppeteer', 'Playwright']}>
  <Tabs.Tab>
With Puppeteer, you have to configure the proxy address when starting
Lightpanda.

```sh copy
lightpanda serve --http-proxy 'http://127.0.0.1:3000'
```

Then you can call `page.authenticate` function to inject your authentication
from your script.

```javascript copy
const page = await context.newPage();

// Set credentials for HTTP Basic Auth
await page.authenticate({
  username: 'my_username',
  password: 'my_password',
});
```

You can find the full example in our
[demo repository](https://github.com/lightpanda-io/demo/blob/main/puppeteer/proxy_auth.js).
  </Tabs.Tab>
  <Tabs.Tab>
With Playwright, configure the proxy when creating the browser's context.

```javascript copy
const context = await browser.newContext({
    baseURL: baseURL,
    proxy: {
      server: 'http://127.0.0.1:3000',
      username: 'my_username',
      password: 'my_password',
    },
});

const page = await context.newPage();
```
You can find the full example in our
[demo repository](https://github.com/lightpanda-io/demo/blob/main/playwright/proxy_auth.js).
  </Tabs.Tab>

## Use a proxy on Lightpanda Cloud

Add the `proxy` query parameter to the [connection URL](/run-on-lightpanda-cloud/getting-started#connect-your-cdp-client-to-lightpanda-cloud) to route the session through a proxy. You have two options: use a shared proxy, or add your own.

### Use a shared proxy

Every account can use two shared proxies.

- `fast_dc`: the default. A single shared datacenter IP, optimized for speed. Each region has its own, so the IP depends on the endpoint you connect to.
- `datacenter`: a pool of shared datacenter IPs with automatic rotation. Accepts an optional `country` parameter (two-letter country code) to target a specific country.

```text copy
wss://euwest.cloud.lightpanda.io/ws?proxy=datacenter&country=de&token=TOKEN
```

Omit `proxy` and the session uses `fast_dc`. [Contact us](mailto:hello@lightpanda.io) for additional proxy options.

### Use your own proxy

Add your proxy on the [proxies page](https://console.lightpanda.io/proxies) in the console, then pass its identifier as the `proxy` parameter. The console generates the identifier and shows it on the proxy's card. It is not the name you gave the proxy.

```text copy
wss://euwest.cloud.lightpanda.io/ws?proxy=xK4mP2qR&token=TOKEN
```

The kind you set on the proxy, datacenter or residential, is a label. It does not change how the session connects.
