| Method | Call | Summary |
|---|---|---|
| [`goto`](/reference/browser-tools#goto) | `await page.goto(url[, { timeout, waitUntil }])` | Open a URL and keep the page in memory |

## Reading the page

| Method | Call | Summary |
|---|---|---|

## Data extraction and scripting

| Method | Call | Summary |
|---|---|---|
| [`evaluate`](/reference/browser-tools#evaluate) | `page.evaluate(script[, { url, timeout, save }])` | Run JavaScript in the page |
| [`extract`](/reference/browser-tools#extract) | `page.extract(schema)` | Extract structured data via a CSS-selector schema |

## Interacting with the page

These methods dispatch real DOM events on the page.

| Method | Call | Summary |
|---|---|---|
| [`click`](/reference/browser-tools#click) | `page.click(selector)` | Click an element |
| [`fill`](/reference/browser-tools#fill) | `page.fill(selector, value)` | Type text into an input |
| [`scroll`](/reference/browser-tools#scroll) | `page.scroll([{ selector, x, y }])` | Scroll the page or an element |
| [`hover`](/reference/browser-tools#hover) | `page.hover(selector)` | Hover over an element |
| [`press`](/reference/browser-tools#press) | `page.press(selector, key)` | Press a keyboard key |
| [`selectOption`](/reference/browser-tools#selectoption) | `page.selectOption(selector, value)` | Select an option in a dropdown |
| [`setChecked`](/reference/browser-tools#setchecked) | `page.setChecked(selector[, checked])` | Check or uncheck a box |

## Waiting

These methods block until the page reaches a condition.

| Method | Call | Summary |
|---|---|---|
| [`waitForSelector`](/reference/browser-tools#waitforselector) | `page.waitForSelector(selector[, { timeout }])` | Wait for an element to appear |
| [`waitForScript`](/reference/browser-tools#waitforscript) | `page.waitForScript(script[, { timeout }])` | Wait until a JS expression is truthy |
| [`waitForState`](/reference/browser-tools#waitforstate) | `page.waitForState(state[, { timeout }])` | Wait for the page to reach a load state |

## Page lifecycle

| Method | Call | Summary |
|---|---|---|
| `close` | `page.close()` | Stales the handle, so later calls on it fail. The page itself is reclaimed on the next `goto` or at script end. |
