## Navigation and search

These methods bring a page into the browser, or save a URL to a file.

| Method | Call | Returns | Summary |
|---|---|---|---|
| [`goto`](/reference/browser-tools#goto) | `await page.goto(url[, { timeout, waitUntil }])` | A promise of the page object it was called on | Open a URL and keep the page in memory |
| [`download`](/reference/browser-tools#download) | `page.download([{ url, path }])` | `saved <bytes> bytes (<content type>) to <absolute path>` | Fetch a URL with the session's cookies into a file |

## Data extraction and scripting

These methods return structured results from the loaded page.

| Method | Call | Returns | Summary |
|---|---|---|---|
| [`evaluate`](/reference/browser-tools#evaluate) | `await page.evaluate(script[, { url, timeout, save }])` | A promise of the script's value as a string, JSON-encoded when it is an object or array. Empty when `save` is set or an async script returns nothing | Run JavaScript in the page |
| [`extract`](/reference/browser-tools#extract) | `page.extract(schema)` | An object or an array, shaped by the schema | Extract structured data via a CSS-selector schema |
| [`classify`](/reference/browser-tools#classify) | `page.classify(questions[, { selector, presets }])` | The category that fits, or an object keyed by question name | Classify page state using semantic questions or presets |
