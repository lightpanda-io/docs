### Meta commands

These commands configure the REPL and never reach the model.

| Command | Description |
|---|---|
| `/help [command]` | List commands, or show help for one |
| `/quit` | Exit the REPL |
| `/verbosity <low\|medium\|high>` | Set agent verbosity |
| `/effort <null\|none\|minimal\|low\|medium\|high\|xhigh>` | Set per-turn reasoning effort |
| `/stream [on\|off]` | Toggle streaming of assistant text |
| `/usage` | Show token usage and cache stats for this session |
| `/clear` | Clear conversation history and usage (keeps page/cookies) |
| `/reset` | Reset conversation and browser session (drops page/cookies) |
| `/save [filename.js] [prompt]` | Save this session to a file |
| `/load <path>` | Load and run a script from disk |
| `/model [name]` | Change the model |
| `/provider [name\|null]` | Change the provider, or 'null' to disable the LLM |
| `/searchEngine <auto\|brave\|tavily\|exa\|keenable>` | Change the web search engine |

### LLM commands

These commands send a prebuilt prompt to the model, so they need a provider.

| Command | Description |
|---|---|
| `/login` | Log in using $LP_* credentials |
| `/logout` | Log out of the current site |
| `/acceptCookies` | Dismiss the cookie consent banner |
